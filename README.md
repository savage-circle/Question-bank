# Question Bank

A full-stack question bank application built with React (frontend) and Deno +
TypeScript (backend), backed by PostgreSQL via Prisma.

## Project Structure

```
question-bank/
├── frontend/       # React application
├── backend/        # Deno + TypeScript API server
├── docs/           # Project documentation
├── .gitignore
└── README.md
```

## Tech Stack

| Layer    | Technology       |
| -------- | ---------------- |
| Frontend | React            |
| Backend  | TypeScript, Deno |
| Database | PostgreSQL       |
| ORM      | Prisma           |
